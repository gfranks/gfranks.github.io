About

A multi-tenant SaaS for lawn care and landscaping companies, built and run by my company, C&F Solutions LLC. Crews work from native iOS and Android apps, owners run the business from a web app, and customers pay and request work through their own portal.

What I built

01

Native iOS (Swift 6, SwiftUI) and Android (Kotlin, Jetpack Compose) apps kept at feature parity, with a Live Activity for the job in progress.

02

Next.js web app, customer portal and internal staff portal on a TypeScript Fastify API with PostgreSQL and Drizzle.

03

An AI assistant built on Claude that returns structured intents, which the API validates and permission-checks by role before acting.

04

Stripe billing and invoice payments, Typesense search, and role-based access control across owners, managers and technicians.

05

Dockerized deploys to staging and production through GitHub Actions.
