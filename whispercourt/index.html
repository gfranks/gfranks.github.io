About

Gossips spread it, skeptics need two sources, and the loyal will expose you. Each turn you whisper, silence, forge or bribe before the rumor travels one more step, and every court can be won in a set number of turns.

What I built

01

A deterministic rules engine in its own Swift package, with no UI code, so every rule is unit-tested.

02

A solver that proves each level's best score; tests fail if a level's par isn't the true optimum or if its new mechanic isn't actually needed.

03

Swift 6 and SwiftUI, with Swift Testing and an XcodeGen project.
